# Tremor Analysis Tool - Cleary Lab, Oregon Health & Sciences University

This is a device our lab created to objectively measure tremor improvement after treatment using Magnetic Resonance Guided Focused Ultrasound (MRgFUS). This technology was used in a cohort of 40 patients, and results are availabe in this [manuscript](https://www.medrxiv.org/content/10.1101/2025.07.29.25332395v1). 

## Hardware
- **Tested Device:** Microsoft Surface Go 3 running Windows 11  
  (Though the software should work on any Windows 10 or 11 system)
- **Accelerometer:** [MbientLab Meta Motion RL](https://mbientlab.com/metamotionrl/)  
- **Stylus:** --
- **3D-Printed Hardware:** (from 'hardware' folder')
  - An **attatchment** for the Meta Motion RL to the stylus  
  - A **tablet holder** to easily hold tablet while patient draws spiral

---

## Software Installation and Usage
- Application is bundled as a '.exe' file. Simply download **'Tremor-Analysis-Tool.exe'** from 'software' folder onto Desktop of tablet, and double click to run.
- Instructions on use (coming soon) in video and typed format available in 'software' -> 'instructions' folders
- Source code in the form of Python files is also availabe in 'software' folder.
